## Evaluation findings

| Evaluation | Winner | With skill | Base | Decisive finding |
|---|---|---:|---:|---|
| Python 3.14 free-threading, standard | Base | 3.7 | 4.5 | The candidate exposed only `[src_NNN]` markers and no usable URLs. |
| TKA analgesia, strict medical | Base | 4.7 | 5.0 | The candidate handled uncertainty well but missed a recent direct 2025 RCT and scoping review. |
| EU AI Act open-source GPAI, strict legal | Candidate | 4.7 | 4.5 | The candidate found Regulation (EU) 2026/1744 and the amended Article 56(6), which base missed. |

The strict legal result demonstrates the intended advantage: a resumable,
multi-axis workflow can catch a material intervening amendment. The standard
and medical results show that internal auditability does not compensate for
missing user-visible links, incomplete freshness sweeps, or excessive cost.

## Runtime evidence

The candidate runs also exposed recoverable orchestration friction:

- intermittent subagent spawn failures before thread creation;
- wait calls below the runtime's minimum timeout;
- concurrent patch attempts against one shared `agent_returns.json`;
- a research-plan patch based on stale template context.

These observations define the v3.2 scope: user-visible URL coverage, isolated
per-agent return files, current-primary-evidence sweeps, bounded retry guidance,
and lower-context merge/review instructions.

## Interpretation limit

This benchmark has three topics and one run per configuration. It is a
directional product benchmark, not a statistically conclusive model study.
Auditability is reported separately and is not treated as a baseline-comparison
quality point.
